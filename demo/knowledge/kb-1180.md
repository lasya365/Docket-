# Legacy IKEv2 fallback profile — temporary remote access

This article is **approved and unchanged**. It is the authority for the
workaround that `kb-2211` described until revision 8 removed it.

## When the fallback profile may be used

A user whose VPN certificate has expired or is being reissued, and who cannot
wait for the reissue to propagate (up to four hours), may be assigned the
legacy profile for a bounded window:

```
vpnctl profile assign --user <upn> --profile corp-remote-legacy --hours 8
```

Maximum window is eight hours. The profile expires on its own; do not extend it
a second time without a security approval.

## Conditions

- The requester's manager must be on the ticket.
- Leave an internal note naming the ticket the reissue is tracked on.
- The profile authenticates with the pre-2023 shared credential, so the session
  is not traceable to a device certificate. Security review every use monthly.
- Clear it as soon as the reissued certificate propagates:
  `vpnctl profile clear --user <upn>`.
