# VPN certificate errors

Applies when the client reports `IKE_AUTH failed: certificate verify failed`,
`peer certificate expired`, or the connection drops within ten seconds of
authenticating.

## Diagnosis

1. **Check the concentrator first.** An outage on the regional concentrator
   surfaces as a generic auth failure for every user at once. Look at the
   network status page before anything else.
2. **Check the client clock.** A device more than five minutes out of sync will
   reject a valid certificate. `vpnctl diag clock --user <upn>`.
3. **Check the issuing CA chain.** `vpnctl cert verify --user <upn>` fails with
   `unable to get local issuer certificate` when the intermediate CA was rotated
   and the client never pulled the new chain.
4. **Read the certificate the client is presenting.**
   `vpnctl cert show --user <upn>` prints the subject, issuer and `notAfter`.

## Resolution

Reissue the user certificate:

```
vpnctl cert reissue --user <upn> --profile corp-remote
```

The user must reconnect once for the new certificate to be installed. Reissue
takes up to four hours to propagate to the regional concentrators.

## Escalate when

- Step 1 shows the concentrator is down: this is an incident, not a ticket.
- The reissue command fails with `CA unavailable`.
- The same user has needed three or more reissues in thirty days.
